一、Genie Master 与 EEP二、WRAM 的结构、方法与能力来源

Genie Master：组织任务

调用什么能力、怎样引导、结果如何、下一步怎么办。

WRAM：生成动作

理解任务、表示当前场景、预测未来变化，并生成机器人动作。

两者属于系统的不同层面；Genie Evolver 则负责后训练。这是公开技术体系的分工，不等于 GO-3 Nano Preview 在 RoboDojo 上已经披露了完整实现链路。[1]

01

Agent 框架：Genie Master连接任务判断、机器人执行与环境反馈

Genie Master 负责组织任务执行：调用机器人能力、下达操作要求、检查执行结果，并在失败后调整安排。它通过 EEP（Embodied Execution Protocol，具身执行协议）统一 Agent 与机器人执行端的交互。[2]

1. EEP 的四类接口

接口作用回答的问题
Capability（能力）向 Agent 声明机器人当前可以调用的能力。能做什么？
Guidance（引导）向底层动作执行端传递操作要求、空间提示和物体参考。这一步怎样执行？
Feedback（反馈）返回执行后的观察、成败情况与卡点信息。实际做成了吗？
Continuity（连续性）保存任务进度、分工与依赖关系，支持中断续作和多机调度。已经做了什么，接下来怎样继续？

四类接口的定义来自 Genie Master 发布稿；空间提示、物体参考等交互细节见配套报道。[2][3]

2. 执行过程中怎样协调？

Agent 读取观察并下达引导 → 底层策略执行 → 返回真实结果 → Agent 决定继续、调整或恢复。

这不是下达一次总指令后，等待机器人把整个任务做完。执行结果会返回 Agent；任务中断后，系统保留已完成进度，再从断点重新规划。[2]

发布稿案例 · 便利店挂货

头部相机看不清被标签遮挡的挂钩 → Agent 回溯失败记录 → 左手靠近并用腕部相机补充近距离视角 → 确认位置后由右手完成挂货。[2]

这次恢复首先改变的是观察方式与执行安排，不是先训练一个新模型再继续任务。

3. 执行经验怎样留下来？

更新路线保留在哪里具体做法更新时机
Harness RSI提示与长期记忆记录成功、失败案例，整理可复用的处理方法，供后续同类任务调用。执行中记录；每日任务结束后统一总结。
Policy RSI动作策略参数将执行、接管和恢复过程产生的数据后处理，再用于训练动作策略。经过数据处理与训练；公开材料没有给出固定频率。

这两条路线在标注“转载自智元”的发布稿中有明确说明。这里不额外推断具体强化学习算法、训练配方或更新频率。[2]

三个时间尺度要分开：当场调整执行方式；事后总结可复用经验；另行训练动作策略。不能把它们都理解为“每做一个动作就更新模型”。
02

具身模型：WRAMWorld Reasoning Action Model · 世界推理动作模型

WRAM 是 GO-3 Preview 的模型架构，连接任务理解、未来状态预测与动作生成。Genie Master 组织任务，WRAM 提供完成操作所需的模型能力。[1]

1. 结构与各模块的作用

部分模块具体做什么
任务理解与推理VLM视觉语言模型结合当前观察与指令，理解任务目标和操作要求。
视觉编码CoAEControl-Oriented Autoencoder
控制导向自编码器		把图像转为适合机器人控制的视觉表示，保留物体位置、形态与空间关系。
未来状态预测SVPSingle-step Visual Planner
单步视觉规划器		根据当前观察和任务条件，通过单步预测机制产生未来状态表示。
动作生成IDMInverse Dynamics Model
逆动力学模型		依据当前状态与预测的未来状态，生成实现这种变化所需的动作。

VLM、CoAE、SVP、IDM 的名称可在发布会结构图中对应；CoAE、SVP 的功能另有官网文字说明。图中没有公开完整的网络层定义、张量尺寸和训练损失。[1][4]

当前观察与任务指令 → 任务理解和控制导向视觉表示 → 未来状态预测 → 动作生成。
这是帮助阅读的功能顺序；不表示所有模块严格串行运行，也不表示必须先渲染出一段完整视频。
帮助理解的例子 · 把杯子放入盒子（非论文实验记录）

先确定杯子与盒子的位置及操作目标；再预测杯子被搬运后的状态；最后生成从当前状态到达目标状态的动作。预测中的成功不等于真实成功，执行后仍须看观察与反馈。

2. KASO：让预测的未来与训练动作对应

KASO（Knowledge-Aligned Selective Optimization，知识对齐选择性优化）是一种训练方法，不是机器人执行时额外调用的控制接口。它针对同一场景可能存在多种合理未来的问题，选择与训练记录中的实际动作更相容的预测进行联合学习。[1]

问题处理方式
同一个场景存在多种合理的未来。比较候选未来与示范动作的相容程度。
预测看起来合理，却与当前示范的操作路径不同。避免将不匹配的未来状态和动作强行配对。
某个预测与真实记录的动作更一致。让该预测参与联合训练，衔接未来预测和动作学习。
帮助理解的例子 · 绕过障碍物

示范记录的是从左侧绕行，预测却对应右侧绕行。两种方案可能都合理，但不能把右侧的未来预测直接与左侧的示范动作当作同一条轨迹监督。

3. 主要训练思路

数据或方法用途
人类第一视角视频提供物体交互过程，帮助学习场景和物理状态怎样变化。
机器人操作轨迹提供观察、动作与真实执行结果之间的对应关系。
数据与模型规模扩展扩大经验覆盖范围，提高模型组织和利用这些经验的能力。
KASO 联合训练降低未来状态预测与示范动作监督之间的错配。

上述训练方向来自智元官网介绍。它们不是已经完整公开的 GO-3 Nano Preview 训练配置。[1]

4. 已公开展示的能力

能力公开展示或说明需要区分的条件
零样本任务迁移将预训练能力用于部分新任务、新场景。不代表所有陌生任务都能直接完成。
少样本适应利用少量额外示范适应更复杂的操作。包含进一步学习或微调。
精细操作乐高零件的抓取、对位和插合。官网示例使用额外示范与微调。
长程任务执行将多个操作步骤衔接为完整拼装过程。还包含 Agent 的任务编排，不应只归因于底层动作模型。

以上是官方发布材料中的能力展示及条件，不是本文独立复现实验的结论。[1]

版本边界：本文整理的是 GO-3 Preview 的公开技术体系。不能把全部结构、训练和部署机制，直接认定为 GO-3 Nano Preview 在 RoboDojo 上的具体配置。

Genie Master 管“调用什么、怎样引导、做得如何、下一步怎么办”；WRAM 管“理解任务、预测变化、生成动作”。执行经验可进入长期记忆，也可经过后处理与训练进入动作策略参数；两种更新不是同一个环节。[1][2]
